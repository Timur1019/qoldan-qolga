# Frontend — Qoldan Qolga

React + Vite. Карта кода и стандарт ревью: [`src/features/README.md`](src/features/README.md). UI-kit: [`src/shared/ui/README.md`](src/shared/ui/README.md).

Сначала бэкенд на порту 8080 (`./gradlew bootRun` в корне репозитория). `/api` и `/ws` проксируются на `http://127.0.0.1:8080`.

```bash
npm install
npm run dev
```

Dev-сервер: порт 3000. Алиас `@/` = `src/`.
